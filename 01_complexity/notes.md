# Time & Space Complexity

## Time Complexity
- Time complexity is computed in terms of Big O notation "Big(O)"
- O(1) — Constant (Best time complexity)
- O(log n) — Logarithmic 
- O(n) — Linear 
- O(n log n) — Linearithmic
- O(n²) — Quadratic

- We do not count input in space complexity

## Important Rules

- Always compute time complexity in terms of worst case scenario 
- Drop constants: O(2n) → O(n)
- Drop smaller terms: O(n² + n) → O(n²)
- Nested loops usually multiply
- Sequential loops usually add
